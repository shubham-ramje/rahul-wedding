# ⚜️ Royal Indian Digital Wedding Invitation | हृदयांश राहुल संग हृदयांशी शिल्पा

A modern, ultra-luxury, royal Indian digital wedding invitation single-page web application built with **React.js**, **Tailwind CSS**, and **Framer Motion**.

---

## 🌟 Highlights & Features

### 1. Royal Aesthetics & Heritage Theme
- **Color Palette:** Deep Royal Maroon (`#4A0404`), Imperial Burgundy (`#2B0303`), Ivory/Cream (`#FFFDF7`), Antique Gold (`#D4AF37`), and Champagne Gold (`#F3E5AB`).
- **Typography:** Google Fonts featuring `Rozha One`, `Yatra One`, `Noto Sans Devanagari`, `Poppins`, and `Cinzel`.
- **Atmospheric Visuals:**
  - Rotating sacred mandala with Lord Ganesha glowing golden emblem (॥ श्री गणेशाय नमः ॥).
  - Interlocking golden couple monogram crest **"R & S"** (राहुल संग शिल्पा).
  - Floating 60fps golden marigold (*गेंदा*) & royal crimson rose (*गुलाब*) petal shower.
  - Ornate SVG Kalash motifs, filigree borders, and glassmorphic gold cards.

### 2. Live Interactive Features
- ⏳ **Live Countdown Timer:** Calculates exact days, hours, minutes, and seconds until **December 13, 2026, 7:00 PM IST**.
- 🎵 **Floating Shehnai / Instrumental Music Player:**
  - Interactive bottom-right floating golden disc with animated equalizer bars.
  - Dual-mode audio system: High-fidelity audio stream with a zero-dependency **Web Audio API synthesizer fallback** playing an authentic Indian classical Shehnai & Tanpura raga (*Raag Yaman*).
- 🗺️ **Venue Integration with Google Maps:** Direct navigation links and click-to-copy address buttons for both venues.
- 💌 **Interactive Blessings & RSVP Wall:** Real-time blessings submission with celebratory golden confetti bursts and local storage persistence.
- 📅 **Google Calendar Integration:** One-click "Add to Calendar" button pre-configured with wedding date and venue details.
- 📲 **Instant WhatsApp Sharing:** Pre-formatted Hindi invitation message for seamless sharing with family and friends.
- 📞 **Click-to-Call Contact Buttons:** Direct phone call triggers for the hosts.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Run in Development
```bash
npm install
npm run dev
```
Open `http://localhost:3000` or `http://localhost:5173` in your browser.

### Build for Production
```bash
npm run build
npm run preview
```
The optimized static build will be generated in the `dist/` directory, ready to be deployed on Vercel, Netlify, GitHub Pages, or Firebase Hosting.
